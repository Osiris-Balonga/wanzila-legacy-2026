# Product references

The source specification is [workflows-user-stories.docx](workflows-user-stories.docx). It defines eight workflows and twenty-four initial user stories.

The proposed V1 contribution contract is [contributions-v1.md](contributions-v1.md); #10 records the inclusion decision and the proposed retention rule. #41 and #42 own implementation and acceptance.

GitHub Issues are the implementation source of truth. If an issue and the source document disagree, resolve the discrepancy in the issue before implementation begins.

Known decisions still requiring explicit product resolution:

- whether saved pharmacies belong in the demonstration scope;
- how emergency contacts appear in mobile navigation;
- whether route guidance is simulated or delegated to an external maps application;
- how deferred reports are protected from automated abuse when #43 is scheduled.
